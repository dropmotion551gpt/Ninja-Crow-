# Ninja Crow - Android APK (GitHub Actions)

1. Is poore folder ko ek naye GitHub repository mein upload karo (branch: main).
2. Repo ke Actions tab mein "Build Ninja Crow APK" khud chalega (ya Run workflow dabao).
3. Build khatam hone par run ke Artifacts se `ninja-crow-debug-apk` download karo.
4. Zip kholo, `app-debug.apk` phone mein install karo (Unknown sources allow karna padega).

Game ki file `www/index.html` hai. Use badalke push karoge to naya APK ban jayega.
